Smart Vehicle Compliance & Fake Number Plate Detection System

A real-time computer vision system that detects vehicle license plates, extracts text using OCR, and verifies plate authenticity by cross-checking with a government database. Designed to identify fake, mismatched, or non-compliant number plates using a combination of detection models, OCR pipelines, and database validation.


🔍 Overview

A real-time Computer Vision system that detects vehicle license plates, extracts the text using OCR, and verifies the plate details against a registered vehicle database to identify fake or non-compliant number plates.

🧠 Key Features

🔸 Real-time license plate detection

🔸 OCR-based text extraction

🔸 Database validation for compliance checking

🔸 Alerts for mismatched, duplicate, or fake plate details

🔸 Modular design for easy deployment and extension

🖥️ Tech Stack

Python

OpenCV

OCR (Tesseract / easyOCR)

Computer Vision (YOLO / Custom CV model)

MySQL / SQLite for plate verification

Flask (optional backend API)
